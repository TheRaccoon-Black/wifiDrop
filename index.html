Data tidak disimpan di server manapun. Murni P2P via WebRTC.
Teknologi

Menggunakan WebRTC DataChannel untuk transfer P2P langsung antar browser. Sinyal koneksi difasilitasi oleh PeerJS (server gratis) — hanya untuk bertukar alamat koneksi, bukan data file. Setelah terhubung, semua data mengalir langsung antar perangkat.
